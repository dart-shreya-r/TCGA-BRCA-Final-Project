**TCGA-BRCA RNA-seq Final Project**

Shreya Ramesh
Foundations of Data Science | Dartmouth College

**Project Overview**

This project analyzes TCGA-BRCA RNA-seq data, focusing on TP53 and BRCA1 gene counts in breast cancer samples.

**Analysis**

The project includes:

Summary statistics for TP53 and BRCA1

Histogram and scatter plot

Violin plot and box plot

Density plot

Heatmap with sample type and pathological stage annotations

**Tools Used**

R, ggplot2, ComplexHeatmap, knitr, and LaTeX.

**Repository Contents**

.Rmd file: R code and analysis
